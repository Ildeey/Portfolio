## 3. ОПИСАНИЕ ПОТОКОВ ДАННЫХ

### 3.1 Основные потоки данных

#### Поток 1: Раскрытие категории (аккордеон)
```
Клик на .cat-col
    ↓
JS проверяет: клик внутри .cat-expanded? → игнорировать (кроме .cat-close)
    ↓
Если колонка уже is-active → collapseAll()
Иначе → expandCol(col):
  - добавить is-active на целевую колонку
  - добавить is-shrunk на соседние
  - добавить has-active на .cat-accordion
    ↓
CSS flex-grow переход (0.45s) расширяет колонку до ~71%
.cat-teaser исчезает (opacity: 0), .cat-expanded появляется
```

#### Поток 2: Открытие модального окна проекта
```
Клик на .cat-project-item (внутри раскрытой категории)
    ↓
JS читает data-category + data-project-id
    ↓
Поиск проекта: projectsData.categories[category].projects.findIndex(p => p.id === id)
    ↓
Заполнение модального окна:
  - #modalImage: src (изображение проекта)
  - #modalTitle: текст (название)
  - #modalDescription: текст (описание)
    ↓
Отобразить #imageModal
    ↓
Навигация Пред./След. ограничена проектами текущей категории
```

#### Поток 3: Счётчик визитов
```
Загрузка страницы
    ↓
JavaScript код измеряет время сеанса
    ↓
Формирование бинарного кода визита (01010101...)
    ↓
Отображение счётчика в footer CTA секции
    ↓
id="visit-stats" + id="time-spent"
```

## 8. БЕЗОПАСНОСТЬ И ВАЛИДАЦИЯ

### 8.1 Валидация входных данных

Форма добавления проектов удалена в v1.1. Проекты хранятся в статическом объекте `projectsData` в `script.js` и редактируются напрямую в коде.

### 8.2 Защита от XSS

- Использование `.textContent` вместо `.innerHTML` где возможно
- Экранирование HTML символов при добавлении динамического контента
- Валидация URL перед добавлением в атрибут src

### 8.3 Безопасность внешних ссылок

```html
target="_blank" rel="noopener noreferrer"
```
- `target="_blank"` - открыть в новой вкладке
- `rel="noopener"` - предотвратить доступ к window.opener
- `rel="noreferrer"` - не отправлять referrer информацию
